Drug-test companion vs “worker with a phone”

The thing you liked is a vibe: a real person, a cheap phone, an app that does one job in the field. The drug-test idea is the same vibe, except the worker is an NCB officer, not a weaver or kabadiwala.

Pick if the only question is “highest chance to win both SSH and SIH”: stay on SIH26231 (field drug-test companion).

Pick if you will only stay awake all night for a civilian worker story: do not take the artisan listing app. Take SIH26229 Kabadiwala Connect, and build it like 26231 (photo → classify → signed receipt).

Head to head: 26231 vs 26229

These two are the real choice. Same skeleton: camera, classify, lock a record, field worker.

Where the artisan app sits

SIH26090 is the prettiest: messy shawl photo → clean listing → Hindi/English copy. It loses to both of the above on win-odds unless you already have a designer and a working image/LLM API with an offline fallback. If the API is down, the product is a camera roll.

Why 26231 still wins the reasoning

SSH is 12 hours. SIH is per-problem. The drug-test brief is a checklist you can tick. Kabadiwala is a ministry novel you can only summarise. Judges at SSH love worker stories; judges at SIH (NCB) love a tool that matches the sentence they wrote.

26231 is a worker-with-a-phone problem. The worker just happens to wear a uniform. If that framing does not get you curious, 26229 is the honest second — same camera + seal trick, warmer story, fatter spec. Build only: lot photo, one price, signed handover.
